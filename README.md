\# Cynbit Backend Technical Audit



A backend engineering assessment project demonstrating API

development, input validation, database persistence, security

practices and automated testing.



\## Project Overview



This project was developed as an independent technical demonstration

for the Cynbit Backend Developer Intern assessment.



It includes:

\- A backend technical audit report.

\- An Express REST API.

\- SQLite database integration.

\- Server-side input validation.

\- Security headers and rate limiting.

\- Automated API and database tests.



Note: This is an independent demonstration implementation.

It is not Cynbit's actual backend system.



\## Technology Stack



\- Node.js

\- Express.js

\- SQLite

\- better-sqlite3

\- Zod

\- Helmet

\- express-rate-limit

\- Jest

\- Supertest
